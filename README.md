# Full-Stack E-Commerce Web Application

A Full-Stack E-Commerce Web Application developed using React and Node.js/Express as part of COMPX322 – Assignment Four at the University of Waikato.

The project consists of two integrated applications:

**Frontend (React)**
- Product browsing and product details.
- Product search and category filtering.
- Price sorting (ascending and descending).
- Shopping cart with quantity management.
- Checkout form with customer validation.
- Responsive user interface using Tailwind CSS.
- React Router for navigation.
- TanStack Query for API and server-state management.

**Backend (Node.js & Express)**
- RESTful API for product management.
- Product listing and category endpoints.
- Individual product details endpoint.
- Order submission endpoint.
- JSON files for product and order data.
- CORS support for frontend integration.

## Technologies Used
- React
- JavaScript
- Node.js
- Express.js
- Tailwind CSS
- React Router
- TanStack Query
- Vite
- REST API
- JSON

## Project Architecture

The React frontend communicates with the Express backend through REST API endpoints.

The backend runs locally on port 3000, while the frontend runs through the Vite development server.

## Project Goals

To develop a functional full-stack e-commerce application demonstrating frontend development, backend API integration, client-side state management, shopping cart functionality, and order processing.
